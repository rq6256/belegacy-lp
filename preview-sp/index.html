大きく2つあります。

    • 認知が広がるまでに時間がかかる

    • 届けたい層に合うメディア選びが大切
    • 二次利用できないと、活用の幅が限られる

Features

が選ばれる理由

動画だけで終わらない。地域に届く発信へ。

  • 理由 01

    YouTubeだけで終わらない
    地方新聞にも広がる

    企画に応じて、地方新聞への掲載も検討。
    動画だけでは届きにくい地域の方にも、
    企業の取り組みを届ける機会が広がります。

    ※新聞掲載には各新聞社による事前審査があり、掲載の可否・掲載時期はお約束できません。

  • 理由 02

    公開後も採用・営業の
    接点で活かせる

    採用ページ、スカウトメール、会社説明会、営業資料へ。
    公開後の活用方法を、
    契約条件の範囲でご案内します。

  • 理由 03

    地域のキーパーソンも
    出演するメディア

    市長など、地域で活動するキーパーソンにも
    ご出演いただいています。
    地域で挑戦を続ける人たちの仕事を届けます。

Flow

制作の流れ

ご契約から公開まで、約8週間の流れ

  1. 1〜2週目

    企画・要件定義

    目的やアピールしたいポイントを
    すり合わせ

  2. 3〜4週目

    構成・準備

    取材内容の設計、
    ロケハン・撮影日程の調整

  3. 5〜6週目

    撮影・編集

    現地取材を実施し、映像を編集

  4. 7〜8週目

    確認・公開

    内容をご確認いただいたうえで
    配信開始

※撮影日程は天候やロケ地の都合で前後する場合があります。
※初稿映像の修正は原則2回まで無料です。大幅な構成変更は別途費用となる場合があります。
※公開後のSNS広告運用やSEO対策も、オプションでご相談いただけます。
